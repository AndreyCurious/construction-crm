# Приёмка

Проверять с облачными аккаунтами из `demo-credentials.txt`. Для разных пользователей используйте отдельные профили браузера или обычное окно и инкогнито.

## Рабочий цикл

| Кто           | Действие                                  | Результат                                               |
| ------------- | ----------------------------------------- | ------------------------------------------------------- |
| Постановщик   | Создать объект и задачу для исполнителя 1 | Статус «Новая», правильный автор, первая запись истории |
| Исполнитель 1 | Взять задачу и отправить на проверку      | «В работе» → «На проверке», оба действия в истории      |
| Постановщик   | Вернуть без комментария                   | Ошибка, статус не меняется                              |
| Постановщик   | Вернуть с причиной                        | «На доработке», причина видна исполнителю               |
| Исполнитель 1 | Исправить и отправить повторно            | «В работе» → «На проверке»                              |
| Постановщик   | Принять                                   | «Принята», дальнейших переходов нет                     |

## Права и интерфейс

- Исполнитель 2 не видит чужую задачу и её историю, в том числе по прямой ссылке.
- Исполнитель видит только объекты со своими задачами; кнопок создания, редактирования и удаления нет.
- После переназначения и обновления страницы прежний исполнитель теряет доступ.
- Непустой объект удалить нельзя. Удаление задачи убирает её из списков, но сохраняет историю в базе.
- В двух вкладках изменить одну запись: второе сохранение старой версии отклоняется с сообщением о конфликте.
- Проверить поиск, статусы, пустые списки, длинные названия и узкий экран.
- Обновить карточку по прямой ссылке, выйти и войти другим аккаунтом: данные прошлого пользователя не показываются.
- Изменить поле в открытой форме, переключить вкладку и вернуться. Повторить при отключённой сети: введённое сохраняется, ошибка обновления не закрывает форму.

## Прямой API

Публичный ключ и пользовательская сессия, без административного ключа:

- Анонимное чтение, регистрация и анонимный вход запрещены.
- Прямые изменения таблиц и любые изменения истории запрещены обеим ролям.
- Исполнитель не может управлять объектами, редактировать задачи или менять чужой статус.
- Неверный переход, устаревшая версия и возврат без непустого комментария отклоняются.
- Изменение пользовательских метаданных не повышает роль.

Проверено через Playwright с облачной базой: обе роли, полный цикл задачи, права доступа, формы, фильтры, конфликт версий, ошибки сети и удаление. Основные экраны проверены при ширине от 320 до 1440 px, включая длинные названия и адреса. `npm run check` проверяет код и SQL локально; облачные Auth и API проверены отдельно.
